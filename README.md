# 晨釣

固定時間起床的釣魚遊戲。鬧鐘響後 3 分鐘內拍下第一張照片，魚就上鉤；照順序拍完路線，把魚釣起來。

https://monmonlee.github.io/morning-fishing/

## 玩法

- **上鉤**：目標時間前 90 分鐘到目標時間後 3 分鐘內，拍下任一路線的第一張照片。這張的時間就是卡片上的「起床時間」。
  - 0–1 分：稀有魚機率加倍｜1–2 分：一般魚｜2–3 分：小魚｜超過：魚跑了
- **收線**：每條路線照順序拍，每一步都有時限，超時就脫鉤。
  - 洗澡：浴巾 → 從淋浴間往外拍門上的藍色三角形（3 分鐘內）→ 洗完澡的淋浴間地板（10–30 分鐘內）
  - 咖啡：滿杯 → 喝完的空杯（2–30 分鐘內）
  - 水：一杯水 → 空杯（1–30 分鐘內）
- **雙餌**：選兩條路線，上鉤後 60 分鐘內都收完就釣起兩條魚；收完一條後 10 分鐘內要開始下一條。
- **魚**：100 種真實的台灣魚，資料來自臺灣魚類資料庫。釣點決定魚池（溪流／海邊，河口魚兩邊都有）；季節魚只在牠的月份出現。圖鑑除了魚種，還收成魚／幼魚、雄／雌、婚姻色。第一版的組合魚會轉成真魚，掛「初代」徽章。
- **週目標**：本週的起床時間鎖定，只能改下週的。
- **壞夜卡**：一個月 2 張，一樣要準時上鉤，收線時限放寬 1.5 倍。
- **手動算過**：照片比對失敗時，一週可以手動算過 2 次。
- **週日大魚**：週一到週六準時 4 天以上，週日必出稀有魚。
- **分享**：每天的魚卡、每週的漁獲卡做成 IG 限動尺寸的圖。

## 照片怎麼比對

只開即時相機，不能從相簿選。每張照片縮成 64×64 算出顏色分佈、明暗格與清晰度，跟範本比完就丟掉，只記時間。範本存的是這組數字加一張 16×16 縮圖。

- 浴巾、藍色三角形：跟範本的相似度
- 地板：像範本那塊地板就算；真正擋偷懶的是「三角形後 10 分鐘才能拍」
- 咖啡空杯：杯子中間的顏色跟滿杯時差很多
- 水：只看有沒有拍

## 怎麼用

用 iPhone Safari 打開網址 →「分享」→「加入主畫面」，之後都從圖示打開。iPhone 鬧鐘只設一顆、關掉貪睡。

資料存在自己手機的瀏覽器裡。換手機或清除 Safari 資料前，記得在「設定」匯出備份。

## 發佈新版

```
scripts/release.sh "這次改了什麼"
```

會更新版本號、commit 並 push。打開中的 app 回到前景時會比對 `version.json`，發現新版就顯示更新按鈕。
